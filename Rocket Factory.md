\# Rocket Factory  
A development planning platform built on TUI (ratatui). Provides a minimalist text and vector graphic interface for planning apps and components.

\#\# Interface

* Layout: Three columns with header bar  
* Left column: Component list  
* Middle/Primary Column: Snap grid layout for staging visually represented pieces  
* Right Column: full breakdown of highlighted component  
* Keyboard only interface: Standard keybinds with unique bindings reserved   
* Components/Pieces: When selected, can be expanded to view or fill functional details of the component.

\#\# Function

* Quickly scaffold and design applications and components  
* Able to push components and features to external locations (eg add items to an associated Nebulous instance  
* Able to retrieve associated component tasks and changes states upon completion (eg component border turns green when tasks associated with it show as complete in Nebulous)  
* Use a combination of toml and md files to record component and feature details as well as push to connected applications depending on required format

\#\# Aesthetics

* Minimalist retro-futuristic appearance  
* Stored themes in ron files with default being the Nebulous/Orrery standard crt amber and black with relevant color differentials for md fields, alerts, etc  
* Components in the central/primary field present as cards with component name, status, and brief description visible; connectible by vector lines
